# fastDev skeletons

The public registry of [fastDev](https://github.com/roma-vibe/fastDev) project skeletons. `index.json`
lists skeleton repositories; fastDev shows them in its library and downloads a skeleton (git clone)
when it is first used. Versions are the `vX.Y.Z` tags of each skeleton repository.

fastDev updates this file when a skeleton is published. To add a skeleton by hand, append an entry:

```json
{ "id": "node-vue", "repo": "https://github.com/roma-vibe/fastdev-node-vue.git", "name": "Node + Vue" }
```
